# 🐦 Flappy Tube Runner: Double Trouble Edition

A fun and addictive Flappy Bird-style game created for Addison!

## 🎮 How to Play

- Press **SPACE** to make the bird fly
- Navigate through the green tubes
- You have **3 lives** - avoid hitting the tubes or the ground!
- After taking damage, you get temporary invincibility
- The game speeds up slightly as you progress
- The bird changes color every 5 tubes
- **Special Easter Egg**: Kevin Durant appears after the 10th tube! 🏀

## 🎯 Features

- Smooth, responsive controls
- Progressive difficulty (speed increases with score)
- Visual effects: particles, screen shake, and flash effects
- Color-changing bird (6 different colors!)
- Parallax scrolling clouds
- Life counter with heart icons
- Score tracking

## 🚀 Getting Started

Simply open `index.html` in your web browser to play!

No installation or dependencies required - it's a pure HTML/CSS/JavaScript game.
